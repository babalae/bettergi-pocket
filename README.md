# BetterGI Pocket

更好的原神（BetterGI）的 Android 口袋版。通过悬浮球在游戏上方提供屏幕识别、自动对话和地图追踪。

## 功能

- **悬浮球**：授权后以气泡形式显示在其他应用之上，可拖动、展开面板
- **屏幕共享**：捕获游戏画面，用于模板识别（Android 14+ 可选择单个应用）
- **自动对话**：识别剧情对话后自动点击选项；可选「快速点击跳过」以点击屏幕下方继续
- **地图追踪**：点击开始，在悬浮窗口中筛选、多选路线或整个目录，依次执行传送、转向、地面行走和拾取；不支持的路线记日志后跳过，可单独开启坐标显示
- **启动原神**：打开已安装的客户端，可选在未检测到游戏时自动启动一次

地图追踪设置支持通过可搜索的下拉多选框配置行走位、生存位短／长战技及水、雷、风、火元素采集的候选角色；可调整优先级、清空和恢复默认，按已选顺序匹配当前队伍。队伍通过 ncnn 头像模型识别，要求单人四人队伍。设置说明、标定范围和验证记录见 [队伍识别与元素采集](docs/队伍识别与元素采集.md)。

支持国服官服、Bilibili 服、国际服、云原神及部分渠道服。

开发时的 Windows 真机打包、安装、启动、截图及无障碍手势验证，见 [真机自动化说明](tools/ANDROID-AUTOMATION.md)。

地图追踪当前标定来自 3040×1904 的安卓平板，地面采集已实测。其他分辨率、飞行和攀爬仍需验证；适配方法与已知限制见 [真机调试经验](docs/地图追踪-真机调试经验.md)。构建所需地图和路线资源通过 `tools/sync-pathing-assets.ps1` 同步，不存入 Git。

## 使用说明

1. 安装并打开应用，按提示开启**悬浮窗**权限
2. 先在应用设置中找到 更好的原神 进行单次授权
3. 在系统设置中开启无障碍服务「更好的原神」（用于模拟点击、判断原神是否在前台）
4. 点开悬浮球，打开**共享屏幕**，在系统弹窗中选择原神画面
5. 按需打开**自动对话**等开关
6. 使用地图追踪时，点击**开始**打开路线与设置悬浮窗口。点目录名称进入，勾选目录会选中全部子目录的路线，也可多选单个文件；选好后点击**执行**，运行期间点击**停止**结束队列。筛选框使用系统输入法，可直接输入中文目录或路线名，也支持拼音、首字母和编号（拼音需要 Android 10+）；设置页可调整小道具间隔、显示坐标。先确认游戏 UI 与当前标定匹配，且路线上的物品尚未采集

地图追踪设置页可切换默认地图匹配方式（模板匹配 / SIFT，初始为模板匹配）。路线未填写匹配方式或值为空时跟随设置，路线指定的方式优先；路线列表会显示实际算法和来源，坐标显示也使用该默认设置。

自动使用小道具支持独立启用开关，使用间隔可通过系统数字键盘输入秒数（如 `0.5`），最多 3 位小数。输入后自动保存，关闭开关会保留间隔。

清理后台后若提示无障碍异常，关闭后再重新打开该服务即可。

## 常见问题

### 遇到“受限制的设置”无法点击？

如果系统提示“受限制的设置”或“出于安全考虑，此设置目前不可用”，请按以下步骤解除限制：

1. **进入应用详情**
    - 返回「设置」主页，点击「应用设置」 → 「应用管理」。

2. **找到目标应用（更好的原神）**
    - 在列表中搜索并点击打开需要授权的那个应用详情页。 

3. **允许受限制的设置**
    - 在应用详情页中，点击右上角的菜单（一般是三个点）或向下滚动，找到并开启 **“允许受限制的设置”**。

![image\.png](docs/images/image%202.jpg)

4. **重新授权**
    - 返回无障碍页面，即可正常开启该应用的无障碍服务。


### 清理手机后再次启动APP无法进行模拟点击？

相关服务会被系统自动杀死，然后出现如下提示：

![image\.png](docs/images/image%206.png)

这时候只要点进去再重新关闭再启用无障碍即可👇

**重新开关权限**：前往手机的“设置” \> “无障碍”（或无障碍功能），找到对应无法运行无障碍的 更好的原神 应用，**关闭其无障碍授权后重新打开**。
