# 手机界面回归样本

这些灰度 PNG 是 3040×1904 横屏游戏画面的局部裁图，用于 `PhoneMapTemplateTest`。只保留识别所需区域，不包含设备状态、账号 UID、完整截图或逐次测试记录。样本独立于生产模板，不能用模板自身覆盖样本。

| 文件 | 原图裁剪区域 `(x, y, width, height)` | 用途 |
|---|---|---|
| main-paimon.png | `(0, 0, 520, 420)` | 主界面派蒙正样本 |
| map-paimon-negative.png | `(0, 0, 520, 420)` | 大地图派蒙负样本 |
| map-settings.png | `(0, 1550, 320, 354)` | 地图设置图标 |
| map-close.png | `(2500, 0, 540, 280)` | 地图关闭按钮及 ROI 坐标偏移 |
| zoom-knob.png | `(30, 680, 160, 560)` | 缩放滑块 |
| teleport-button.png | `(2000, 1680, 280, 160)` | 已打开传送面板的按钮 |
| teleport-button-negative.png | `(2000, 1680, 280, 160)` | 未打开面板的相同区域 |
| waypoints.png | 五块 `103×130` 地图区域横向拼接 | 多锚点识别及重复命中抑制 |

`waypoints.png` 中每块保留锚点周围 20 像素地形。原图锚点模板左上角分别为 `(1789,839)`、`(2056,672)`、`(2287,347)`、`(1979,1084)`、`(1901,1528)`；未粘贴生产模板。其他裁图的期望中心坐标在测试中明确断言。
